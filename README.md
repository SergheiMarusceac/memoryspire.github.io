# MemorySpire

Studio site for MemorySpire — games, production tools, and digital assets.

**Philosophy:** Simple by default. Modular by design. Powerful by choice.

## Structure

Single static page, no build step, no dependencies.

- `index.html` — the entire site (markup, styles, and mark inlined)

## Deploy

Hosted via [Cloudflare Pages](https://pages.cloudflare.com/), connected to this repo.
Push to `main` → auto-deploys.

## Local preview

Just open `index.html` in a browser. No server required.
